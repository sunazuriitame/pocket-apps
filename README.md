# Pocket Apps

スマホのホーム画面に置いて使う、小さな静的Webアプリ。ビルド不要、依存なし、1ファイル完結。

- **kakei/** — 家計の見張り番。現金と電子マネーの月枠、ATMに行った回数、次の入金日までの資金繰りを見る
- **tatekae/** — 立て替えメモ。立て替えと返済を記録して貸し残高を出す

## データの扱い

入力した値はすべて、閲覧している端末の `localStorage` にのみ保存される。
サーバーへは一切送信しない。このリポジトリにも個人の数値は含まれない。
金額・日付・枠などは初回起動時に利用者自身が入力する。

端末間の移動とバックアップは、各アプリの「書き出し」「読み込み」（JSON）で行う。

## iOSで使うとき

Safariで開く → 共有 → ホーム画面に追加。
**ホーム画面のアイコンから開くこと。** Safariのタブとホーム画面アプリは保存場所が別になる。
